# Anonymous University Platform with ZKP

Monorepo for a full-stack TypeScript application using pnpm workspaces.

## Project Structure

- `src/backend`: Express + TypeScript API server
- `src/frontend`: React + TypeScript + Vite web app
- `src/shared`: Shared TypeScript types used across packages

## Prerequisites

- Node.js 20+
- pnpm 10+

## Getting Started

```bash
pnpm install
pnpm dev
```

## Common Commands

```bash
pnpm dev
pnpm build
pnpm typecheck
```
